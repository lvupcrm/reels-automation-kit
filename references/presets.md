# 편집 스타일 프리셋 10종

사용자가 **"N번 스타일로 만들어줘"** 또는 스타일 이름을 말하면 이 문서의 해당 항목을 그대로 적용한다.
지정이 없으면 소재·주제에 맞는 프리셋 2개를 추천하고 하나를 고르게 한다(기본값은 **01 네온 하이라이트**).

> 프리셋은 **화면의 옷**이다. 어떤 파이프라인(P1~P6)으로 뽑든 그 위에 입힐 수 있다.
> 예: 나레이션 몽타주 + `06 브루탈 네온`, 화면 녹화 + `03 박스 라벨`.
> 공통 규약(톤매핑·단일 패스 마스터·QA·커버)은 SKILL.md를 그대로 따른다. 아래는 **차이나는 값만** 적는다.

| # | 이름 | 한 줄 성격 | 음성 | 어울리는 소재 |
|---|---|---|---|---|
| 01 | 네온 하이라이트 | 기본값. 강조 자막 + 인트로 타이틀 | 나레이션 | 무엇이든 |
| 02 | 키네틱 타이포 | 글자가 화면에 배치되는 스타일 | 나레이션 | 숫자·대비 메시지 |
| 03 | 박스 라벨 튜토리얼 | 단계별 설명, 저장 유도 | 무음 | 화면 녹화·사용법 |
| 04 | BGM 감성 타이포 | 명조·저채도·느린 호흡 | 무음 | 공간·일상·브랜드 |
| 05 | 미니멀 화이트 | 흰 레터박스, 담백한 자막 | 나레이션 | 제품·인터뷰·에세이 |
| 06 | 브루탈 네온 | 강한 브랜드 프레임 | 나레이션 | 브랜드·공지·런칭 |
| 07 | 뉴스 자막바 | 정보 전달, 하단 바 | 나레이션 | 소식·업데이트·팁 |
| 08 | 타이포 카드 리스트 | 카드↔실사 교차, N가지 | 무음 | 리스트·체크리스트 |
| 09 | 스플릿 스크린 | 상하 2분할 비교 | 나레이션 | 전후·비교·데모 |
| 10 | 줌 펀치 | 짧고 빠른 단어 임팩트 | 무음+효과음 | 훅·티저·인트로 |

## 01 · 네온 하이라이트 (기본)
- **자막**: 가석원체 84px · 중앙(MarginV 758) · 외곽선 5 · 강조색 `#FCED00`(줄당 1단어)
- **타이틀**: `make_typo.py title` 인트로 3.2초 + `overlay=0:227` + `fade=out:st=2.6:d=0.5:alpha=1`
- **효과음**: 타이틀 0.3s impact · 마무리 ding
- **컷**: 3~4초, 실사·자료 섞기
- 그대로 두면 이 스타일이다. 특별한 요청이 없을 때의 안전한 선택.

## 02 · 키네틱 타이포
- **자막**: `make_subs.py --style kinetic` — 하단 바 없이 화면에 배치, Pretendard·무외곽선
  - phrases 문법: `텍스트 | pos=x,y an=4 size=1.9`, 빈 줄 = 블록 경계
  - 핵심어(숫자·대비)는 `size 1.9~2.3`으로 키워 위계를 만든다
  - 큰 사이즈 문구가 화면 폭을 넘으면 **자동 줄바꿈에 맡기지 말고 줄을 나눠 각각 pos 배치** (겹침 사고 방지)
- **필수**: 외곽선이 없어 배경을 탄다 → **어두운 컷만 고르고** `eq=brightness=-0.06`으로 한 번 더 눌러준다. 밝은 배경 구간엔 `box=1`.
- **컷**: 2~3초, 2~3컷이면 충분(짧게 끝낸다)

## 03 · 박스 라벨 튜토리얼
- **무음 출력**(`-an`) — 업로드 시 트렌드 음원을 얹는다
- **훅 카드**: 주황 라운드 박스 `#E16506` + 흰 가석원체 2줄 + 아래 흰 바 "저장하고 따라하세요"
- **단계 라벨**: 상단 y210 검정 박스(alpha 242) + 흰 글자 `1. / 2. / 3.`
- **구성**: 인물 훅 → 화면 데모 3컷(각 라벨 1개) → 인물 아웃트로
- 화면 녹화가 있을 때 가장 강하다. 실녹화가 없으면 목업(`make_mockup.py`)으로 대체.

## 04 · BGM 감성 타이포
- **무음 출력** · 컬러 `eq=saturation=0.52:brightness=0.02:contrast=1.05`
- **자막 카드**: 고운바탕(명조) 74px 2줄 중앙 · 카드 뒤 **소프트 딤 밴드**(y700~1080, 최대 alpha 150, blur 22)로 가독성 확보
- **전환**: `xfade=transition=fade:duration=1.0` · 컷당 6~7초(느리게)
- **카드 페이드**: `fade=in:st=0.4:d=0.9:alpha=1` / `fade=out:st=<끝-1.4>:d=0.9:alpha=1`
- 감성 스타일은 외곽선을 쓰지 않는다 — 대신 딤으로 대비를 만든다.

## 05 · 미니멀 화이트
- **레터박스**: 영상을 `scale=1080:1350` 후 `pad=1080:1920:0:285:color=white` (상하 흰 여백)
- **자막**: Pretendard 64px · 무외곽선(Outline 0, Shadow 1) · 흰색 · 하단 여백 안쪽(MarginV 250)
- **컷**: 3~4초, 정적인 화면 위주. 화면이 조용해야 산다.

## 06 · 브루탈 네온 (ai-MKT 브랜드)
- **고정 프레임 오버레이**: 좌상단 워드마크(Bagel Fat One, 슬래시만 네온) + 네온 코너 크롭마크 4개 + 하단 해저드 스트라이프
- **컬러**: 네온 라임 `#C5FE01` × 잉크 `#0A1113`
- **자막**: 가석원체 78px · MarginV 700 · 강조 네온
- **배경**: `eq=brightness=-0.04`로 눌러 네온을 띄운다
- 브랜드 채널 고정 스타일. 로고·색을 바꾸면 다른 브랜드에도 그대로 쓸 수 있다.

## 07 · 뉴스 자막바
- **프레임**: 하단 반투명 검정 바(y1310~1560, alpha 205) + 상단 네온 라인 + 좌상단 카테고리 태그 칩
- **자막**: Pretendard 62px · 무외곽선 · **바 안쪽**(MarginV 430)
- **컷**: 3초 고정 리듬(정보형은 규칙적인 게 낫다)
- 소식·업데이트·팁처럼 "읽는 콘텐츠"에 쓴다.

## 08 · 타이포 카드 리스트
- **무음 출력** · **카드↔실사 교차**: 풀스크린 카드(1.9초) → 실사(2.3초) 반복
- **카드**: 잉크 배경(alpha 232) + 네온 숫자 `01/02/03`(Bagel Fat One 300px) + 흰 문구(가석원체 96px) + 네온 언더라인
- "N가지" 리스트형 대본과 짝을 이룬다. 항목은 3~5개가 적당.

## 09 · 스플릿 스크린
- **레이아웃**: 상단 960px + 하단 960px `vstack` — 각각 `scale=1080:960:force_original_aspect_ratio=increase,crop=1080:960`
- **분할선**: 네온 16px 바 + 상하 라벨 칩(무엇과 무엇을 비교하는지)
- **자막**: 하단 화면 아래쪽(MarginV 180)
- 전후 비교·지시와 결과·화면과 현장을 동시에 보여줄 때.

## 10 · 줌 펀치
- **무음 + 효과음**: 컷 전환마다 whoosh(volume 0.5), 마무리 impact(0.55) → `loudnorm=I=-16`
- **줌**: 소재를 `scale=1188:2112` 후 `crop=1080:1920` (10% 확대) — 컷마다 화면이 다가온 느낌
- **단어 카드**: 가석원체 210px 한 단어, 네온/흰 교차, 외곽선 16 + 드롭섀도
- **컷**: 2.5~3초 4컷 = 11초 안팎. 훅·티저용이라 짧게 끝낸다.

## 자막 공통 스펙 (프리셋마다 값만 다르다)
| 항목 | 기본 | 비고 |
|---|---|---|
| 크기 | 74~84px | 화면 높이의 3~4% |
| 강조 확대 | `--emph-scale 3.0~4.0` | 강조어는 1~4자로 짧게 |
| 글자색 / 외곽선색 | 흰 + 검정 | 밝은 배경이면 진한 글자 + 흰 외곽선으로 뒤집는다 |
| 외곽선 두께 | 기본 6~7 / 강조 14~20 | 강조는 2~3배 |
| 위치 | MarginV 758 (중앙 아래) | 레퍼 모사 시에는 계측값 우선 |
| 표시 시간 | 최소 1.1초 | 초대형 강조는 읽을 시간을 준다 |

## 적용 규칙
1. 프리셋을 정한 뒤 **대본·컷시트 단계에서 어떤 스타일인지 사용자에게 알린다**("06 브루탈 네온으로 갑니다").
2. 프리셋의 자막 스펙은 `make_subs.py` 실행 후 ASS의 `Style: Sub` 줄을 편집해 맞춘다(폰트·크기·외곽선·MarginV·색).
3. 사용자가 "자막 더 크게" 같은 개별 수정을 요청하면 프리셋 값을 벗어나도 된다 — 프리셋은 출발점이지 잠금이 아니다.
4. 한 계정에 스타일을 3개 이상 섞지 않도록 권한다. 피드가 산만해진다.
