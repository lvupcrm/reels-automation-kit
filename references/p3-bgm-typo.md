# P3 — BGM+타이포형

말 없는 B-roll에 **타이포 카드만 얹어 무음 마스터**로 뽑는다. 음원은 인스타 업로드 시 트렌드 음원을 입힌다(도달에 유리하고 저작권도 안전하다).

**적용 조건**: 입력 영상에 말소리가 없고(현장·운동·일상 스케치), 나레이션 없이 텍스트로 메시지를 전달할 때. 제작이 가장 빠르다.

## 1. 텍스트 스토리 (Claude가 직접 작성)
- 맥락 로드는 P1 대본과 동일(`PROFILE.md`의 톤·타깃·금기). 금기도 동일(과장·공포·미검증 수치).
- 구조: 후킹 1문구 → 포인트 2~3문구 → CTA 1문구. 총 5~7문구, 문구당 강조 1줄 + 보조 1줄.
- 컷 리듬: 문구당 1.8~2.5초(읽기 속도 기준), 총 15~25초. 나레이션이 없으므로 **읽을 시간이 곧 컷 길이** — 긴 문구는 쪼갠다.

## 2. 컷 구성
- 영상을 프레임 피크로 훑어 문구와 어울리는 구간을 골라 문구 수만큼 트림한다(문구 리듬과 컷 전환을 일치시킨다).
- 세로 변환·HDR 톤매핑은 공통 규약. 원음은 `-an`으로 제거.

## 3. 타이포 오버레이
- 문구별 `scripts/make_typo.py overlay "보조 문구" "강조 문구" ov_N.png` → 각 컷에 `overlay=0:0` + 배경 `eq=brightness=-0.05`.
- 하단 ASS 자막은 **없다** — 나레이션이 없으므로 타이포 카드가 자막을 겸한다.
- 타이틀 인트로 3.2초 + 커버 프레임 (공통 규약).

## 4. 무음 마스터 + 전달
- 마스터 렌더는 공통 규약(단일 패스). 오디오 스트림 자체를 넣지 않는다(`-an`) — 무음 트랙을 넣는 것보다 인스타에서 음원 입히기가 깔끔하다.
- 전달할 때 안내 한 줄을 반드시 붙인다: "업로드할 때 인스타에서 트렌드 음원을 입혀주세요 — 컷 리듬은 문구 기준 N초 간격입니다."
