# 제작 프리셋 B — 롱테이크·일상 브이로그

> P3의 **롱테이크 변형**. 폰으로 찍은 생활 클립 1~3개 + 그날 있었던 일을 받았을 때 쓴다(육아·반려동물·가게 일상).
> 모티베이션 몽타주(빠른 컷·비트 그리드)와 **정반대 포맷** — 편집을 최소화하는 것이 핵심이다.
> 스크립트: `scripts/preset_longtake/` (timeline.py · build_master.py · mg_overlay.py · qa_strip.py · peek_sheet.py) — `reel_<슬러그>/`에 복사해 쓴다.
> 레퍼런스 근거: 좋아요 3만+ 육아 롱테이크 — 49.5초, **컷 전환 0회**, 작은 관찰 자막, 현장음만.

## 입력 (이것만 받으면 시작)
- 세로 클립 1~3개 (연속 촬영이면 `ffprobe`의 `creation_time`으로 이어지는지 먼저 확인)
- **그날 무슨 일이 있었는지 한 줄** — 화면에 안 나오는 맥락(누가 먼저 갖고 있었는지, 누구 물건인지)은 반드시 사용자에게 듣는다.
  추측하면 서사가 통째로 뒤집혀 전면 재작업이 된다(실제로 겪었다).
- 레퍼런스 URL(있으면) → 내려받아 구조 실측

## 확정 구조
| 요소 | 값 |
|---|---|
| 길이 | 45~50초 (레퍼런스 길이에 맞춤) |
| 컷 | 점프컷 4~6회만. **크롭·줌·슬로모·비트 컷 금지** |
| 타이틀 | 잘난체(없으면 가석원체) 116px + 부제 46px, y=430, 0~2.6초 |
| 자막 | Pretendard Black 54px 흰색 + 검은 외곽선 5px + 소프트 섀도. 어둠 띠 없음 |
| 자막 위치 | y=430(주인공이 하단일 때) / y=470(주인공이 화면을 채울 때). **주인공을 피해 배경 쪽** |
| 오디오 | 현장음 유지. 컷 경계 0.08초 페이드, loudnorm −16 LUFS |
| 그레이딩 | `eq=contrast=1.03:saturation=1.05`만. 비네트·노이즈 없음 |
| 끝 | 0.5초 페이드아웃 |

## 자막 톤
관찰 코멘트를 **반말 일기체**로. `ㅋ`·`ㅠ`를 그대로 쓴다. 존댓말·설명체 금지.
- 좋은 예: "목욕하자니까 일단 숨음" / "찾았다ㅋ" / "씻은 건 난데 왜 네가 지쳐"
- 나쁜 예: "강아지가 목욕을 싫어하고 있습니다" (설명체·존댓말)
- 웃음 포인트 1개를 마지막 근처에 둔다 — 상황의 아이러니를 한 줄로 짚는다.

## 브이로그 몽타주 변형 (여러 장소·여러 클립일 때)
같은 엔진으로 컷 수를 늘린 버전이다. 나들이·행사처럼 장면이 여럿이면 이쪽.
- `fit=(cx,cy,zoom,aspect)`: 가로 소스를 **블러 배경 위 4:5 프레임**으로 얹는다(억지로 9:16 크롭하면 사람이 잘린다).
- 현장음은 컷마다 `atrim/afade` 후 concat — 슬로모 컷은 audio 0.
- 클로즈업 크롭은 `peek_sheet.py --grid`로 잰다(프리셋 A의 순서 2 참조).

## 순서
1. `ffprobe`로 회전·HLG·길이·`creation_time` 확인 → 연속 촬영이면 한 서사로 붙인다
2. `peek_sheet.py <영상>:0:0:1:10`으로 클립별 프레임 시트(1초 간격) → 장면 전환점 파악. 핵심 구간은 0.25~0.5초 간격으로 다시
3. **사용자에게 맥락 확인** (화면 밖 사실)
4. 레퍼런스가 있으면 `select='gt(scene,0.10)',showinfo`로 컷 수, 자막 크롭으로 폰트 크기·위치 실측
5. `timeline.py` CUTS 작성 → `python3 timeline.py`로 합계 검증
6. `mg_overlay.py` TITLE·CAPS 작성 → 실행하면 **자막 겹침·폭 검사가 먼저 돈다**(겹치면 멈춘다)
7. `build_master.py preview_540.mp4 --preview` → `qa_strip.py preview_540.mp4`로 1초 간격 시트 → **자막 문구와 그 순간 실제 동작이 맞는지 프레임으로 대조**
8. 사용자 OK → 마스터 렌더 → 720p 확인본 → 전달

## 함정
- **서사 추측 금지** — 화면에 안 보이는 선후관계를 짐작해 캡션을 쓰면 전면 재작업이 된다.
- 캡션 타이밍은 반드시 프레임 시트로 검증한다. "엎드려서 통곡"이라 썼는데 그 시점엔 앉아 있는 식의 어긋남이 잦다.
- 아이·동물 소리는 whisper 전사 신뢰도가 낮다(환각으로 원본보다 긴 문장이 나오기도 한다). 캡션 근거로 쓰지 않는다.
- 아이폰 HLG를 톤매핑 없이 섞으면 색이 물빠진다 — `HDR` 집합에 소스 키를 넣는다.
- 아이·가족이 나오는 영상은 **공개 범위를 사용자에게 한 번 확인**한다(얼굴·이름·장소가 드러나는 프레임).
