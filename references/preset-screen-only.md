# 제작 프리셋 D — 화면 전용 설명편 (얼굴 없음)

> P4(앱 데모)의 변형. **용어·개념·도구 설명편은 화면이 논지 그 자체라 얼굴 없이 성립한다.**
> 촬영이 필요 없고, 직전 편과 같은 옷·배경이 연달아 나가는 재탕 문제도 피한다.
> 도구: `scripts/screen_cards.py`(캡처·브라우저 카드·터미널 카드·프레임 렌더) · `scripts/layout.py`(좌표 정본) · `scripts/word_subs.py`(자막)

## 좌표는 인물 편과 다르다 — 그대로 쓰면 하단 절반이 빈다
인물이 배경을 채우는 편의 값(카드 880x622·y430·자막 y1120)을 쓰면 화면 아래가 텅 빈다. 화면 편은 **카드가 배경을 대신한다.**

| 요소 | 값 (`layout.py`) |
|---|---|
| 화면 카드 | **980x1010 · x50 · y360** · 라운드 22 |
| 카드 위 라벨 | y228(번호 뱃지+한글) · y306(영문 병기) |
| 자막 중심 | **y1450** (MarginV 438) — 카드 아래. 하단 1494로 UI 가림선(1580)·CTA 안전선(1500) 안쪽 |
| 터미널 본문 | **42px / 행간 62** — 46px면 `http://localhost:3000` 한 줄이 카드 폭을 넘어 잘린다 |

## 화면 소스
- **웹페이지**: `screen_cards.py capture <URL> page.png --viewport 640x940` → `browser page.png <주소> card.png`
  - 뷰포트를 카드 비율에 맞춰 **작게** 잡는다 — 페이지 글자가 커진다(2배 해상도로 저장된다). 실제 창을 찍으면 글씨가 폰에서 안 읽힌다.
  - 신호등·주소창·자물쇠는 그려서 합성한다. 주소는 실제 URL을 그대로 넣으므로 증거성은 유지된다.
  - Node.js가 없으면 사용자가 직접 캡처한 PNG를 받아 `browser`만 쓴다.
- **터미널·에디터**: 실제 명령을 돌려 나온 출력을 `terminal lines.txt card.png`로 렌더한다(한글·영문 고정폭 한 폰트, 없는 기호는 자동 대체).
- **네이티브 앱 화면**: 화면 녹화 권한이 없는 환경에선 `screencapture`가 검은 화면만 뱉는다. 사용자가 캡처한 PNG를 받거나, 캡처 앱(CleanShot 등)의 URL 명령을 쓴다.

## ⚠️ 내 실제 프로젝트·계정 화면을 찍지 않는다
실제 프로젝트를 찍으면 키·고객 정보가 프레임에 들어간다. **더미 데이터로 채운 데모 앱/계정을 따로 만들어** 찍는다(이름은 `김OO`).
- 데모 앱 주소가 릴스에 나오면 영상 수명 동안 살려둔다. 팀 계정 배포는 기본으로 로그인 보호가 켜져 있을 수 있다 — 외부에서 열리는지 확인.
- 입문자 말투로 실제 커밋을 쌓아두면(`git log --oneline`) 그 자체가 소재가 된다.

## 렌더 — 프레임 직접 합성
소스가 전부 PNG면 컷별 중간 인코딩이 필요 없다. `screen_cards.py render`가 PIL로 전 프레임을 합성해 ffmpeg에 파이프로 흘리고,
자막(ASS)·나레이션까지 **한 번에 인코딩**한다. filter_complex 셸 변수 함정도, 컷별 재인코딩 화질 저하도 함께 피한다.
```bash
python word_subs.py words n0.wav n1.wav n2.wav -o words.json          # 청크별 전사 → 절대 타임라인
python word_subs.py ass words.json phrases.txt --y 1450 -o subs.ass  # 화면 편 자막 위치
python screen_cards.py render timing.json master.mp4 --audio narration.wav --ass subs.ass --bg bg.png --title title.png
```
- `timing.json`의 컷 경계 = 화면 전환 지점 = 나레이션 청크 경계(청크 사이 gap의 절반). 같은 화면을 두 청크가 쓰면 한 컷으로 묶는다.
- 카드 등장 0.26초(26px 상승+페이드), 오버레이 0.14초 뒤 페이드, 타이틀 1.42초부터 0.4초 페이드아웃이 기본.
- 30초 920프레임에 약 40초 걸린다.

## 대본
- 용어 N개형: 훅(내가 막혔던 벽) → "저는 이 N개에서 막혔어요" → 용어마다 **한 줄 비유**(로컬=가오픈, 배포=정식 오픈, 커밋=공사 전 사진) → 다음 편 예고 + 댓글 CTA.
- 비유 한 줄이 화면 카드와 붙어야 한다 — 카드에 그 비유의 증거(주소창의 localhost, git log의 되돌리기)가 보이게 고른다.
