# 제작 프리셋 A — 모티베이션 몽타주 (+ 프리즈 오프너)

> P3(BGM+타이포형)의 **모티베이션 변형**. 실제 센터 현장 촬영본(그룹 운동 클립 11개)으로 만들어 검증한 구조다.
> "모티베이션 영상처럼", "레퍼런스처럼 리듬감 있게", 그룹 운동·현장 스케치 클립 여러 개 + 취지/카피를 받았을 때 쓴다.
> 스크립트: `scripts/preset_motivation/` — 작업 폴더 `reel_<슬러그>/`에 **폴더째 복사**한 뒤
> `timeline.py`의 SRC·HDR·CUTS와 `mg_overlay.py`의 BLOCKS만 바꿔 쓴다(프리즈를 쓰면 `freeze_fx.py` 상단 문구까지).
> 레퍼런스 분석 근거: 130 BPM 힙합 프로모 릴스(31초, 컷 72회, 드롭 6.8초·클라이맥스 20~23초 스트로브, 글자 없이 로고 범퍼).

## 입력 (이것만 받으면 시작)
- 세로 클립 N개 (6개 이상 권장). 해상도는 상관없다 — 크롭이 비율로 계산된다. 4K 세로면 펀치인 1.6배까지 선명하다.
- 취지 한 줄 + 카피 덩어리(있으면). 없으면 `PROFILE.md` 톤으로 6~9줄 직접 쓴다.
- 레퍼런스 릴스 URL(있으면) → 내려받아 BPM·컷 리듬 실측: 장면 전환 `select='gt(scene,0.25)'`, 온셋 자기상관.

## 확정 구조 (16마디 = 896f = 29.87초, 비트 14f = 128.6 BPM)

| 마디 | 구간 | 컷 리듬 | 텍스트 |
|---|---|---|---|
| 1~2 | INTRO **프리즈 오프너**(기본 켜짐) | 분위기 28f → 주인공 28f → 정지 42f → 이어재생 14f | 타임스탬프 타이핑(정지 전 종료) → 프리즈 카드(브랜드/타이틀/설명) |
| 3~4 | BUILD | 2비트 | 감정 라인 2개 |
| 5 | DROP | 플리커 2f×7 → 홀드 42f + 흔들림 | 글자별 슬램 1줄 |
| 6~8 | MONTAGE 1 | 1비트(14f), 일부 2비트 | 서브+키 블록 |
| 9~10 | HERO | 슬로모 0.5x 2컷 | 서브+키 블록 |
| 11 | MONTAGE 2 | 반비트(7f) + 휩 1f | 블록 |
| 12 | CLIMAX | 휩 3f 컷 3개 + 흔들림 → 흰/검 플리커 | 2줄 키 |
| 13~14 | RESOLVE | 슬로모(웃는 얼굴) → 걸어옴 | 관계 라인 |
| 15~16 | OUTRO | 와이드 팬 → 로고 범퍼(어둡게 0.55) | 마무리 블록 → 로고 + 태그라인 |

- 구간별 프레임 합계는 `section()`이 assert로 지킨다. 16마디가 아니면 실행이 멈춘다.
- 각 컷 = `C(src, start, n프레임, speed, crop=(cx,cy,zoom), bump, shake, whip_in, whip_out, label)`.

## 기법 (build_master.py가 단일 패스로 처리)
- **펀치인 크롭**: 소스에서 9:16 창의 1/zoom 영역을 잘라 1080x1920. 가로 소스도 같은 식으로 된다.
- **비트 범프**: `1+0.05*exp(-14*mod(t+phase,beat))` — 컷 시작 프레임의 위상을 전역 비트에 맞춘다.
- **흔들림**: 1.03 여유 확대 후 `crop x=+amp*sin(t*97)`, `y=amp*0.8*cos(t*73)`.
- **휩 블러**: `avgblur=sizeX=71:sizeY=1` 컷 경계 1~3f(수평 스미어). 슬로모는 `setpts/speed → minterpolate`(입력을 0.15초 더 읽고 trim + `tpad stop_mode=clone`).
- **플리커**: 2f 컷 7개 + 오버레이의 흰/검 프레임 교대.
- **그레이딩**: contrast 1.08 · brightness +0.02 · saturation 0.95 · 섀도 쿨(colorbalance) · vignette PI/7 · noise 4(마스터만).
- 체인 끝마다 `setsar=1` 필수 — 크롭 비율 오차로 concat SAR가 어긋나면 렌더가 죽는다.
- 입력은 컷마다 `-ss/-t`로 따로 연다(50입력도 정상). split+trim 방식은 버퍼 드롭 위험이라 쓰지 않는다.
- 아이폰 HLG 소스는 `HDR` 집합에 키를 넣으면 크롭 앞에서 톤매핑된다.

## 자막 (mg_overlay.py)
- 키·서브 **Pretendard Black** 흰색 + 소프트 섀도, 뒤에 어둠 띠(alpha 0.32). 타임스탬프만 가석원체.
- **대형 워드마크·빨간 밑줄은 넣지 않는다** — 검증 때 "카피가 묻힌다"며 뺐다.
- 블록 = `(시작f, 끝f, 서브, 키, 키크기)`; 키는 `\n`으로 2줄. 폭 940 초과 시 자동 축소. 6f 팝(1.12→1.0), 마지막 3f 페이드.
- 슬램 = 글자별 스태거(1f 간격, 7f 팝 2.0→1.0 오버슈트).
- 로고 범퍼: 작업 폴더에 `logo.png`를 두면 쓴다. 배경이 불투명한 로고도 **명도 마스크**로 흰 실루엣을 뜬다(알파를 쓰면 흰 사각형이 된다). 없으면 `BRAND` 글자로 대신한다.
- 이모지는 폰트에 글리프가 없다 → 캡션에만 쓰고 자막에선 "!"로.

## 프리즈 오프너 (기본 켜짐)
**영상 재생 → 순간 정지 → 얼린 화면에 패널·타이포 → 같은 샷 이어재생.** 등장 인물·이벤트 소개 오프너다.
총 길이·비트 그리드는 그대로 두고 **INTRO 2마디(112f) 안에서만** 재배치한다.

- 스위치: `timeline.py`의 `FREEZE = dict(f0=56, n=42, src_cut=dict(src, start, n, crop))`. 빼려면 `FREEZE = None`.
  `src_cut`은 얼릴 직전 컷과 **완전히 같은 값** — `freeze_card.py`가 그 컷의 필터 체인을 그대로 돌려 마지막 프레임을 뽑아 이음매가 없다.
- 순서: `freeze_card.py`(스틸) → `freeze_seg.py`(사람 누끼 — 첫 실행 때 모델 176MB를 한 번 받는다) → `mg_overlay.py` → `build_master.py`.
- 층(아래→위): 뭉갠 배경(채도 0.30·남색 틴트·블러 22·1.04 확대·1.00→1.03 푸시인) → 망점 → 집중선(누끼 무게중심에서 방사) → 종이결 → 빨강 패널+흰 점선(−7°) → 톱니 리빌 8f → 글자별 스태거 타이포 → 누끼(흰 스티커 외곽 7px·그림자·빨강/흰 에코 수렴) → 마름모 비네트.
- 바꾸는 곳: `freeze_fx.py` 상단 `BRAND/TITLE/DESC`, `TSIZE/CX/CY`, `LAG`.
  - 패널 위치는 **누끼 알파로 글자 가림률을 크기×위치 격자 탐색**해 최소점으로 정한다(하단 캡션·우측 버튼 안전영역 안). 검증작은 104px·(600,1400)·가림 5.5%.
  - 패널 여백은 비대칭 — 앞 인물이 겹치는 쪽을 넓혀 글자 대신 빨간 면만 가리게 한다.
- **누끼 확인**: `freeze/mask_preview.jpg`(왼쪽 원본·오른쪽 초록 바탕 누끼)를 눈으로 본다.
  - 사람이 안 잡히면(커버리지 3% 미만) 누끼 층 없이 진행된다 → 인물이 크게 나온 컷으로 `src_cut`을 바꾼다.
  - 화면 대부분이 잡히면(55% 초과) 바닥·손에 든 물건까지 딸려온 것이다 → **전신이 보이는 와이드 컷**이 가장 깨끗하다.
- 함정:
  - **베이스 드리프트**: 앞선 컷들의 fps 재샘플로 정지 구간이 1f 당겨진다(f56 의도 → f55 실측). 오버레이 없이 렌더해 `tblend=difference`로 정지 시작을 재고 `LAG`에 넣는다. 섬광은 2f 폭으로 둬 ±1을 흡수한다.
  - **가석원체는 초성 ㄹ이 ㅌ처럼 렌더**된다(큰 크기에서 "록"이 "톡"으로 읽혔다). 프리즈 타이틀은 직접 넣은 잘난체 > 도현 순으로 잡힌다. 새 폰트는 자모 스윕 렌더로 확인한다.
  - 흐린 전경 제거는 픽셀 단위가 아니라 **연결 성분 단위**로 한다 — 픽셀로 자르면 검은 옷 같은 평탄면에 구멍이 난다.

## 순서
1. 소재 판별(공통 규약) + 클립별 프레임 시트(`preset_longtake/peek_sheet.py <영상>:0:0:0.5:12`) → 클로즈업 후보와 (cx,cy) 메모
2. **클로즈업 (cx,cy)는 그리드 프레임으로 잰다**: `peek_sheet.py --grid <영상> <초>` (960px + 10% 눈금).
   썸네일로 읽으면 머리카락 덩어리를 얼굴로 착각한다(두 번 연속 절반쯤 빗나갔다). 머리 폭이 9:16 창보다 크면 zoom 1.0.
3. 레퍼런스가 있으면 BPM·컷 리듬 실측. 없으면 128.6 BPM(14f) 기본
4. `timeline.py` CUTS 작성 → `python3 timeline.py`로 합계 검증 (프리즈를 쓰면 freeze_card → freeze_seg 먼저)
5. `mg_overlay.py` BLOCKS 작성(취지+카피 섞어 6~9줄) → `python3 mg_overlay.py`
6. `python3 mock_strip.py` → 목업 스트립으로 크롭·자막 검수
7. `python3 build_master.py preview_540.mp4 --preview`(약 45초) → 프리뷰 전달, **사용자 OK 게이트**
8. 곡이 정해지면 BPM 차이만큼 전역 속도 보정(±3% 이내) → `build_master.py master.mp4`(crf 18 slow) → 커버·컷시트
9. **무음 마스터**로 전달 + 안내: "업로드할 때 곡의 드롭 시각 − 7.5초를 시작점으로 잡으세요". 비즈니스 계정은 인기곡 라이브러리가 제한될 수 있다.

## 소요 (검증 실측)
첫 제작은 클립 11개·방향 수정 3회 포함 약 1시간 반. 프리셋이 있으면 **컷 선정(프레임 시트 판독)이 대부분**이라 프리뷰까지 20~30분.
카피만 바꾸는 재작업은 오버레이 수 초 + 프리뷰 45초.
