# 제작 프리셋 C — 인물 인서트 (토킹·인터뷰·녹음 원음)

> P2(토킹헤드)의 확장. 사람이 나오는 영상을 **담백한 컷**으로 두고, 말하는 순간에 맞춰 **단어별 자막·키워드 팝·흐린 배경 위 모션그래픽**을 얹는다.
> 협찬 릴스 40여 개 버전을 거쳐 승인된 문법이고, 카메라를 보지 않는 투샷(대화 장면)에도 그대로 통했다.
> 도구: `word_subs.py`(자막) · `mg_kit.py`(모션그래픽) · `voice_tools.py`(목소리·녹음 검수) · `layout.py`(좌표)

## 확정 문법
| 요소 | 값 |
|---|---|
| 자막 | Pretendard Black 66 · 흰 · 외곽선 2.5 · 그림자 3 · 이탤릭. **단어(구)마다 위치를 박는다**(`\an5\pos`) — 줄 폭 885 넘으면 자동 축소 |
| 키워드 | 말하는 순간 **민트 #00FB98** + 90→110→100% 팝. 줄마다 1~2개(숫자·핵심 명사) |
| 부정·반전어 | 코랄 #FF5762 + 짧은 흔들림 ("안 됩니다"·"못") |
| 자막 위치 | 중심 **y1080**, 인서트 구간은 **y1640~1680**(카드 아래). 판정은 줄의 **중간 시각** |
| 인서트 | 인물 배경 유지 + `gblur=sigma=14` + `drawbox black@0.65` → 중앙 큰 카드/선화 모션그래픽(알파 MOV) + 위 작은 라벨. 흰 선화 + 민트 포인트 |
| 컷 | 담백하게. 강조 순간만 **펀치인 1.08~1.12**(zoompan, 0.28초). 휩·플리커 없음 |
| 그레이딩 | `colorbalance=gm=-0.015:gh=-0.010,eq=contrast=1.015:saturation=0.96` (거의 원본) |
| 속도 | 나레이션·대화 **1.15~1.2배**가 기본(승인본 1.2). 빠른 편은 1.3까지 |
| 효과음 | 한 편 6~7회 — 시작 whoosh · 인서트/손가락 tick · 클릭 · 확인/CTA ding, 선형 볼륨 0.22~0.5 |
| 타이틀 | 영상 안 타이틀 카드는 짧게(0~1초 유지 → 1~2.5초 페이드) 또는 없음. 타이틀은 **커버에** 넣는다 |

```bash
python word_subs.py words 청크1.wav 청크2.wav … -o words.json       # 나레이션: 청크별 전사 → 절대 타임라인
python word_subs.py map 원본words.json jumpcut_segments.json -o words.json   # 실음성: 원본 시각 → 점프컷 타임라인
python word_subs.py ass words.json phrases.txt --insert 4.1-8.9 --insert 15.2-20.6 -o captions.ass
python mg_kit.py cards mg1.mov --labels "릴스,카드뉴스,강의 자료" --title "콘텐츠 자동화" --dur 4.8
```
인서트 합성 필터는 `mg_kit.py` 상단 주석 그대로 쓴다. 인서트 창과 `--insert` 값은 같은 숫자여야 한다.

## 인서트(모션그래픽) 규칙
- **알파는 반드시 ProRes 4444**(`-c:v prores_ks -profile:v 4 -pix_fmt yuva444p10le`). VP9(yuva420p) 알파는 overlay에서 먹지 않아 **인물이 검게 가려지는 버그**가 여러 번 반복됐다. `mg_kit.py`가 이 규격으로 뽑는다.
- 요소는 1080 폭 기준 **카드 300px 이상** — 첫 판(240px)은 폰에서 작아 보였다.
- 인서트는 4~5.5초, 한 편 3~4개. **정지 카드·대기 화면을 길게 늘리면 인물 리듬이 죽는다** — 늘린 버전은 "전께 훨씬 좋아"로 폐기됐다.
- 결과물마다 설명 멘트·"AI에게 이렇게 요청" 시연 대사를 붙이지 않는다 — 결과 이미지 자체가 가치를 보여주게 한다.
- **부분 확대**가 필요하면 전체 zoompan 대신 화면을 split해 그 영역만 1.5배로 키워 얹는다(세로 앵커 47%, 0.3초 스무스스텝) — 가장자리를 잃지 않는다.
- **화면 속 버튼 강조**: 좌표 몇 점을 찍어 보간하고 큐빅 이즈로 링+리플을 띄운다. 새 효과음은 넣지 말고 **원본의 실제 클릭 소리**에 맞춘다. 손끝 자동 추적은 얼굴 같은 고채도 영역을 잘못 잡는다 — 그리드 프레임으로 좌표를 직접 잰다.
- 코드로 못 그리는 아이콘은 AI 이미지 생성(순수 초록 배경·흰 테두리 스티커·글자 없음) → 초록 키잉(`g>r*1.12 & g>b*1.12 & g>90`, MinFilter+Blur). 픽셀을 손으로 그린 아이콘은 "흐릿하다"는 지적을 받았다.
- 새로 재구성한 화면(시연용)에는 **"화면 재구성" 라벨**을 단다 — 실제 촬영 결과로 오인하지 않게.

## 자막 세부
- **발화와 자막 표기는 분리**한다 — 말은 "엠씨피", 자막은 "MCP". (word_subs의 서열 정렬이 표기 차이를 흡수한다)
- 큰 타이포·카드가 같은 문구를 보여주는 시간창에서는 **그 줄 자막을 뺀다** — 화면이 두 번 읽힌다.
- 속마음·독백 비트는 일반 자막과 **다른 스타일**(더 크게, 문장 전체 강조색, 더 아래)로 구분한다.
- ⚠️ ASS 알파는 직관과 반대다 — `&H00`=불투명, `&HFF`=투명. 외곽선을 `&HD0000000`으로 넣으면 81% 투명이 되어 밝은 배경에서 자막이 사라진다(`&H14000000`으로 교정).

## 녹음 원음을 증거로 끼우기 (인터뷰·반응)
대본으로 쓴 말은 주장이지만 **남이 실제로 뱉은 말은 증거**다. 나레이션(흰 자막) 사이에 실제 대화 원음을 끼운다.
- **구조**: 나레이션 구간은 빨리 넘기는 몽타주, 원음 구간은 실시간 1배속 + **줄 전체 강조색 자막**(`> ` 문법) + 좌상단 배지(「현장 반응」 등).
  인터뷰형이면 Q=실음성(강조색 자막 + 배지 「Q. 질문자」) / A=나레이션(흰 자막 + 배지 「A. 저」), 화자가 바뀔 때마다 컷.
- **화자 구분은 내용으로 추론하지 말고 F0로 잰다**(`voice_tools.py f0 녹음.wav 3.2-5.8 11.0-14.5`). 전사 도구의 화자 라벨은 전원 한 사람으로 뭉치거나 반대로 붙는다 — 직관과 반대인 경우가 실제로 있었다. 애매하면 샘플을 잘라 사용자에게 들려준다.
- **자르기**: 단어 타임스탬프로 후보를 잡고 `voice_tools.py cut`으로 20ms RMS 최저점에서 자른다(whisper 경계는 수십 ms 틀린다). 문두 어절("네·이렇게·맞아요")을 whisper가 흘리는 일이 잦으니 앞쪽 0.28초 여유.
- 볼륨만 `highpass=90,loudnorm=I=-15`로 맞추고 **배속·피치는 건드리지 않는다** — 가공하면 증거성이 죽는다.
- 짧은 클립은 whisper가 흔들린다 → 자막은 **긴 문맥 전사본**의 문장을 고정해 쓴다.
- **금액·욕설·실명** 발화는 클립째 뺀다. 제3자 목소리는 **발행 전 본인 동의**, 특정될 문장은 제외하거나 뜻만 살려 뭉갠다.
- 원음 구간 배경으로 가로 데스크 영상을 9:16 블러로 쓰지 않는다(천장만 남아 새까맣게 죽는다) — 세로 원본을 쓴다.

## 대사 보완 — 재촬영 없이
- 문장을 잇거나 고칠 땐 새 TTS보다 **같은 화자의 다른 테이크에서 그 단어를 찾아** 크로스페이드로 붙이는 쪽을 먼저 본다.
  접속어("그래서")는 따로 붙이지 말고, 화자가 한 호흡에 이어 말한 테이크에서 **접속어까지 통째로** 잘라 쓴다(이음매 게인 −3dB).
- TTS로 보완할 수밖에 없으면 문장 전체가 아니라 **빠진 음절·어절만** 최소 단위로 만들어 끼운다.
- 보완한 대사는 **얼굴 위에 얹지 않는다**(입모양이 안 맞는다) — 화면·제품 컷이나 블러 B-roll 위에 얹는다. CTA 문장을 나중에 추가할 때도 원본 출연자 음성 + 블러 B-roll이면 재촬영 없이 이어진다.
- 접합부는 사람이 듣기 전에 **수치로 먼저 거른다**: 접합 전후 F0 급상승·레벨(RMS dBFS) 점프가 기준 안인지.

## 속도 — 전역 리타이밍
완성 편집본을 다시 편집하지 않고 **배속만** 바꿀 수 있다. `tempo = 목표배속 / 기존배속`으로 모든 컷·레이어·자막·효과음 시각을
`새 시각 = 기존 시각 / tempo`로 재계산하고, 음성엔 피치 보존 `atempo`만 건다. 두 시리즈에서 1.15→1.20(→1.30)으로 이렇게 확정했다.
- 효과음 시각은 절대 초가 아니라 **컷 경계 기준 상대값**으로 들고 있어야 배속이 바뀌어도 자동으로 따라온다.
- 배속만 하면 톤이 밋밋해질 때: `asetrate`로 피치 +5% → `atempo`로 속도 복원 → `treble` 부스트.
- 라이브 육성 훅은 배속을 걸지 않고 EQ(treble +1.8)+loudnorm으로 톤만 맞춰 배속 구간과 잇는다.

## 효과음·믹스
- 임팩트(셰이크·플래시·클릭)는 물리적 동작 시점이 아니라 **말·자막이 튀는 시점**에 건다 — 자막·소리·화면이 같이 튀어야 자연스럽다.
- 여러 짧은 소리로 된 복합 효과음은 타임라인에 흩뿌리지 말고 **한 wav로 미리 합성**해 한 번만 배치한다.
- 같은 샘플은 한 편에 3회 이상 쓰지 않는다.
- 나레이션 버스: `highpass=f=65` + 약한 컴프(threshold 0.14·ratio 1.5·attack 20·release 180) → 효과음을 나레이션 사이드체인으로 덕킹(threshold 0.045·ratio 4·attack 5·release 110).

## 대본 구조
- **6단계**: 훅 → 문제 → 해결(달라지는 점) → 기능(그 변화를 만드는 것) → 방법(직접 쓰는 과정) → CTA. 같은 설명을 두 단계에서 반복하지 않고, **가장 긴 시간은 '방법'**에 준다.
- 문제 제기는 구체 상황을 짧은 자막으로 나열하다가 **한 줄 질문으로 수렴**시킨다.
- 인과가 어긋난 문장은 버린다("치면서 정리된다 → 맥락이 빠진다"처럼 좋은 행위가 나쁜 결과로 이어지는 문장) — 문제를 다시 정의해 축을 바꾼다.
- "완료했다"는 주장에는 **완료 화면 증거**가 있어야 한다. 없으면 그 문장을 빼거나 증거를 먼저 확보한다.
- 추상 개념은 같은 화면에서 **한 요소만 바꿔** 대비시킨다(주소창만 localhost ↔ 실제 주소).

## CTA
- 두 문장 순서 고정: **혜택·제공 제시 → 행동 지시(댓글 키워드)**. 순서가 바뀌면 다시 만든다.
- 키워드형 vs 자유형: 낯선 외래어를 정확히 쳐야 하는 키워드면 자유형("아무 말이나")이 낫고, 브랜드명 댓글을 쌓거나 링크 발송이 목적이면 키워드형이 낫다.
- 댓글 자동응답은 **포함(contains) 매칭 + 변형어**(조사·느낌표·영문 표기)를 같이 등록해야 실제 댓글을 놓치지 않는다.
- 정보 구간 → CTA 구간은 은유 모션그래픽 + 짧은 브리지 문장(2~2.5초)으로 완충한다. 브리지를 넣으면 이후 모든 컷·레이어·자막 시각을 **스크립트로 일괄 오프셋**한다(손으로 밀지 않는다).

## 검수 (이 프리셋에서 추가)
- 부분 수정 뒤엔 **오디오 스트림 해시를 직전 버전과 비교**해 의도한 구간 밖을 안 건드렸음을 확인한다(재인코딩이 불가피하면 영상 SSIM·오디오 상관계수).
- 컷 순서를 바꾸거나 대사를 접합했으면 최종 믹스를 **통째로 재전사**해 누락·중복 단어가 없는지 본다.
- 자동 검증과 **사람 귀 검수는 구분**해 보고한다 — "음색·자연스러움은 청취 확인 전"이라고 적는다.
- 프레임 검수는 확대가 아니라 **실제 재생 크기(가로 400px 안팎 축소본)**로 한다 — 확대에선 보이던 외곽선·알파가 축소하면 안 보인다.
