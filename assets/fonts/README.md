# 폰트 라이브러리

자막·타이틀에 쓰는 한글 폰트 모음입니다. 상업적 이용이 가능한 것만 담았습니다.

## 쓰는 법

**설치 없이** 쓸 수 있습니다. 클로드에게 폰트 이름을 말하면 됩니다.

```
자막 폰트를 "[폰트 이름]"으로 바꿔줘. 폰트는 04_폰트 폴더에 있어.
```

## 폰트가 없어도 됩니다

아무것도 지정하지 않으면 **컴퓨터에 기본으로 있는 한글 폰트**로 자막이 나옵니다
(맥은 Apple SD Gothic Neo, 윈도우는 맑은 고딕). 먼저 한 편 만들어보고 느낌을 바꾸고 싶을 때 골라 쓰세요.

## 팁

- 릴스 자막은 **굵은 폰트**가 잘 읽힙니다. 얇은 폰트는 영상 위에서 묻힙니다.
- 타이틀과 자막을 다른 폰트로 쓰면 산만해집니다 — 한 편에 한 폰트를 권합니다.
