# 릴스 자동화 — 프롬프트 라이브러리

> 클로드에게 그대로 복사해 붙여넣는 **주문 문장 모음**입니다.
> 큰따옴표 안이나 대괄호 `[ ]` 부분만 내 것으로 바꿔 쓰세요. 나머지는 손대지 않아도 됩니다.

## 쓰는 법 세 줄

1. 영상을 작업 폴더의 `input` 안에 넣습니다.
2. 아래에서 상황에 맞는 프롬프트를 골라 붙여넣습니다.
3. 클로드가 **대본과 컷 구성을 먼저 보여주면**, 고칠 걸 말한 뒤 "좋아, 진행해"라고 합니다.

> 💡 결과물이 마음에 안 들면 다시 만들 필요 없습니다. **"자막 더 크게"처럼 고칠 점만 말하면** 그 부분만 다시 렌더합니다.

# 1. 처음 한 번만 — 프로필과 목표 만들기

이걸 먼저 해두면 대본의 말투·타깃·표현이 확 달라지고, 주제 추천도 내 사업에 맞게 나옵니다. 클로드가 질문하며 채워줍니다.

```
내 프로필 파일(PROFILE.md) 만들어줘. 필요한 걸 질문해서 채워줘.
```

직접 적고 싶다면 이렇게 주세요.

```
작업 폴더에 PROFILE.md 만들어줘. 내용은 아래야.

- 업종·역할: [예: 동네 필라테스 센터 원장]
- 타깃 시청자: [예: 운동을 시작하려는 30~40대 직장인]
- 파는 것: [예: 그룹 수업 회원권, 1:1 레슨]
- 말투: [예: 존댓말, 편안한 구어체]
- 금기: [예: 과장·공포 마케팅 금지, 가격 노출 안 함]
```

**목표 워크북**도 하나 만들어 두세요. "왜 릴스를 올리는가"가 있어야 주제·대본이 목적지를 향합니다.

```
목표 워크북(GOALS.md) 만들어줘. 필요한 걸 질문해서 채워줘.
```

직접 적는다면:

```
작업 폴더에 GOALS.md 만들어줘. 내용은 아래야.

- 릴스로 이루려는 것: [예: 체험 수업 예약 늘리기, 팔로워 만들기]
- 보는 사람이 했으면 하는 행동: [예: 프로필 링크 클릭, DM 문의]
- 올릴 빈도: [예: 주 2회]
- 찍을 수 있는 소재: [예: 수업 현장, 내 얼굴, 센터 공간]
- 찍기 어려운 소재: [예: 회원 얼굴은 못 나감]
```

# 2. 기획 — 주제·콘티부터 시작하기 (선택)

영상을 먼저 찍고 넣어도 되지만, **찍기 전에 여기부터 시작하면 결과물이 눈에 띄게 좋아집니다.**
대본에 필요한 그림을 알고 찍는 것과, 있는 영상에 대본을 맞추는 것의 차이입니다.

## 주제가 막막할 때 — 주제 추천

프로필·목표를 바탕으로 클로드가 주제를 뽑아줍니다.

```
내 프로필이랑 목표 보고, 이번 주 올릴 릴스 주제 5개 추천해줘.
주제마다 어울리는 대본 유형이랑 첫 문장(훅)도 한 줄씩 붙여줘.
```

## 찍기 전에 — 콘티(촬영 리스트) 뽑기

주제가 정해지면 뭘 어떻게 찍을지 리스트로 받습니다. 폰으로 보면서 찍기만 하면 됩니다.

```
주제: "[정한 주제]"
이걸로 콘티 짜줘. 대본 초안이랑, 컷마다 뭘 어떤 구도로 몇 초씩 찍으면 되는지
촬영 리스트로 뽑아줘. 폰 보면서 찍게 간단하게.
```

## 찍어온 뒤 — 콘티대로 제작

```
아까 콘티대로 찍어서 input 폴더에 넣었어. 그 콘티 기준으로 만들어줘.
```

## 따라 만들고 싶은 릴스가 있을 때 — 레퍼런스 분석

잘 만든 릴스의 링크(인스타·유튜브·틱톡)나 영상 파일을 주면, 그 릴스의 **편집 문법**(구성·훅·자막 스타일·컷 리듬)을 분석해서 내 소재로 재현해 줍니다.

```
이 릴스처럼 만들어줘: [링크 또는 영상 파일]
주제: "[내가 전할 내용]"
```

분석만 먼저 받고 싶다면:

```
이 릴스 어떻게 만든 건지 분석해줘: [링크]
```

클로드가 레퍼런스를 **자동으로 계측**합니다 — 컷 길이, 자막 위치·크기·색, 타이틀 위치, 카드 구간까지 숫자로 뽑아서 그대로 맞춥니다. 결과가 레퍼와 다르면 이렇게 말하세요.

```
레퍼런스랑 자막 크기(또는 위치·색·폰트)가 달라. 측정해서 맞춰줘.
```

> ⚠️ 참고하는 건 **구성과 스타일**입니다. 남의 영상·대본·음원을 그대로 복사하면 저작권 문제가 됩니다 — 분석 후 촬영은 내 소재로 합니다.

> 💡 콘티 없이 그냥 찍은 영상을 넣어도 됩니다(3장). 기획은 어디까지나 선택입니다.

# 3. 편집 시스템 6종 — 어떤 영상이냐에 따라 고르세요

영상을 넣고 아래 중 하나를 쓰면 됩니다. **잘 모르겠으면 맨 아래(자동 판별)를 쓰세요.**

## ① 내가 말하는 영상 — 토킹헤드 자막형
카메라를 보고 말한 영상. 원래 목소리를 살리고 군더더기를 잘라냅니다.

```
input 폴더의 영상으로 릴스 만들어줘.
내가 카메라 보고 말하는 영상이야. 원래 목소리 살리고, 말 사이 빈 구간은 잘라줘.
```

## ② 말 없는 현장 영상 + 하고 싶은 말 — 나레이션 몽타주형
현장·작업 스케치에 내 목소리(또는 AI 목소리) 나레이션을 얹습니다. **가장 많이 쓰는 유형입니다.**

```
input 폴더의 영상들로 릴스 만들어줘.
주제: "[여기에 하고 싶은 말 한 줄]"
```

## ③ 분위기 영상만 — BGM + 타이포형
나레이션 없이 자막 카드만 얹어 무음으로 뽑습니다. 업로드할 때 인스타 트렌드 음원을 입히면 됩니다.

```
input 폴더의 영상으로 릴스 만들어줘.
나레이션 없이 타이포(자막 카드)만 얹어서 무음으로 만들어줘.
주제: "[전하고 싶은 메시지]"
```

## ④ 화면 녹화 — 앱 데모 튜토리얼형
프로그램·앱 사용법을 보여줄 때.

```
input 폴더의 화면 녹화로 릴스 만들어줘.
주제: "[무엇을 어떻게 하는지]"
중요한 동작은 확대해서 보여줘.
```

## ⑤ 제품·음식·공간 — 제품 등장형
실물이 주인공일 때. 클로즈업 위주로 짧게 끊어줍니다.

```
input 폴더의 영상으로 제품 릴스 만들어줘.
제품: "[제품명]"
강조할 점: "[예: 수제, 당일 제조, 크기]"
```

## ⑥ 남의 콘텐츠에 반응 — 리액션형
원본 영상과 내 반응 영상을 함께 넣습니다. 위에 원본, 아래에 내 얼굴이 배치됩니다.

```
input 폴더에 원본 영상이랑 내 반응 영상 넣어놨어. 리액션 릴스 만들어줘.
반응할 포인트 먼저 짚어주면 그거 보면서 다시 찍을게.
```

> ⚠️ 남의 콘텐츠를 쓰는 방식이라 **사용 권한이 있는 영상**으로 만드세요. 출처 표기가 함께 들어갑니다.

## 자동 판별에 맡기기
어떤 유형인지 모르겠을 때. 클로드가 영상을 보고 골라서 이유를 알려줍니다.

```
input 폴더의 영상 보고 어떤 릴스 유형이 맞을지 판단해서 만들어줘.
주제: "[하고 싶은 말]"
```

# 4. 대본 유형 13종 — 같은 영상, 다른 이야기 방식

위 편집 시스템에 **이야기 구조**를 얹습니다. 주문 끝에 한 줄 덧붙이면 됩니다.
해외에서 실제로 잘 터진 교육형 숏폼 포맷을 유형별로 정리한 것입니다.

| # | 유형 | 덧붙일 문장 |
|---|---|---|
| 1 | **분해 설명형**<br><sub>Breakdowns / Explainers</sub> | `어려운 개념 하나를 쉽게 분해해서 설명하는 구조로 대본 짜줘.` |
| 2 | **사례 분석형**<br><sub>Case Studies</sub> | `실제 사례 하나를 뜯어보며 왜 그렇게 됐는지 짚는 구조로 대본 짜줘.` |
| 3 | **문제 해결형**<br><sub>Problem Solution</sub> | `흔한 문제를 짚고 해결책을 주는 구조로 대본 짜줘.` |
| 4 | **흔한 실수형**<br><sub>Common Trap / Mistake</sub> | `사람들이 자주 빠지는 함정과 피하는 법을 알려주는 구조로 대본 짜줘.` |
| 5 | **튜토리얼형**<br><sub>Tutorial</sub> | `따라 할 수 있게 단계별로 알려주는 구조로 대본 짜줘.` |
| 6 | **리스트형**<br><sub>Listicle</sub> | `"○가지"로 나열하는 구조로 대본 짜줘. 각 항목은 짧게.` |
| 7 | **상황극형**<br><sub>Scenarios</sub> | `"이런 상황이라면?" 하고 상황을 설정해 보여주는 구조로 대본 짜줘.` |
| 8 | **비교형**<br><sub>A vs B (vs C) Comparison</sub> | `두 가지를 비교해서 뭐가 다른지 보여주는 구조로 대본 짜줘.` |
| 9a | **질문 답변형**<br><sub>Q&A</sub> | `자주 받는 질문에 답하는 구조로 대본 짜줘.` |
| 9b | **인터뷰 클립형**<br><sub>Interview Clips</sub> | `질문을 받고 답하는 인터뷰 느낌으로 대본 짜줘.` |
| 10 | **랭킹·티어형**<br><sub>Ranking / Rating / Tier List</sub> | `순위를 매기거나 등급을 나눠 보여주는 구조로 대본 짜줘.` |
| 11 | **레벨형**<br><sub>Levels</sub> | `초급부터 고급까지 단계를 올려가며 보여주는 구조로 대본 짜줘.` |
| 12 | **리액션형**<br><sub>Reaction</sub> | `무언가를 보고 반응하며 짚어주는 구조로 대본 짜줘.` |

**예시 — 합쳐서 쓰기**
```
input 폴더의 영상들로 릴스 만들어줘.
주제: "필라테스 처음 오시는 분들이 가장 많이 하는 걱정"
사람들이 자주 빠지는 함정과 피하는 법을 알려주는 구조로 대본 짜줘.
```

> 💡 **어떤 유형이 좋을지 모르겠다면** 이렇게 물어보세요.
> ```
> 이 주제에 어울리는 대본 유형 3개만 추천하고, 이유도 한 줄씩 알려줘.
> ```

# 5. 편집 스타일 10종 — 같은 영상, 다른 분위기

편집 시스템(3장)이 "무엇을 찍었나"라면, 스타일은 **"어떻게 보이게 할까"**입니다. 번호만 말하면 됩니다.

```
input 폴더의 영상들로 릴스 만들어줘.
주제: "[하고 싶은 말]"
6번 스타일로 만들어줘.
```

| # | 스타일 | 어떤 느낌 | 어울리는 소재 |
|---|---|---|---|
| 1 | **네온 하이라이트** | 기본. 강조 자막 + 인트로 타이틀 | 무엇이든 |
| 2 | **키네틱 타이포** | 글자가 화면에 배치되는 요즘 스타일 | 숫자·대비 메시지 |
| 3 | **박스 라벨 튜토리얼** | 단계별 설명, 저장 유도 | 화면 녹화·사용법 |
| 4 | **BGM 감성 타이포** | 명조체·차분한 색·느린 호흡 (무음) | 공간·일상·브랜드 |
| 5 | **미니멀 화이트** | 흰 여백 + 담백한 자막 | 제품·인터뷰·에세이 |
| 6 | **브루탈 네온** | 강한 브랜드 프레임 | 브랜드·공지·런칭 |
| 7 | **뉴스 자막바** | 하단 바, 정보 전달 | 소식·업데이트·팁 |
| 8 | **타이포 카드 리스트** | 카드와 영상이 번갈아 (무음) | "N가지" 리스트 |
| 9 | **스플릿 스크린** | 위아래 2분할 비교 | 전후·비교·데모 |
| 10 | **줌 펀치** | 짧고 빠른 단어 임팩트 (무음+효과음) | 훅·티저 |

> 💡 **어떤 게 어울릴지 모르겠다면** 이렇게 물어보세요.
> ```
> 이 영상이랑 주제에 어울리는 스타일 2개만 추천해줘. 이유도 한 줄씩.
> ```

**스타일을 내 것으로 바꾸기** — 프리셋은 출발점입니다. 고른 뒤에도 계속 고칠 수 있어요.
```
6번 스타일로 하되 강조색은 [#색상코드]로 바꿔줘.
5번 스타일인데 자막은 조금 더 크게 해줘.
방금 그 스타일 마음에 들어. 앞으로 기본으로 써줘.
```

# 6. 검증된 제작 프리셋 4종 — 실제 발행작의 레시피 그대로 (v2.0 신규)

실제로 만들어 올리고 반응까지 확인한 편의 구조를 **그대로 복사해 값만 바꿉니다.** 같은 완성도가 나옵니다.

## A. 모티베이션 몽타주 — 운동·현장 클립 여러 개를 비트에 맞춰
```
input 폴더 영상들로 모티베이션 몽타주 릴스 만들어줘.
취지: "[예: 주말 아침 야외 러닝 프로그램 소개]"
카피: "[하고 싶은 말 몇 줄 — 없으면 알아서 써줘]"
```
- 처음에 영상이 **멈췄다가 소개 카드가 뜨고 다시 이어지는 오프너(프리즈)**가 기본으로 들어갑니다. 빼려면 `프리즈 오프너 없이`.
- 로고를 넣으려면 로고 파일을 같이 주세요: `로고는 input/logo.png 써줘`
- 음원 없이(무음) 나옵니다 — 인스타에서 음원을 얹을 때 "곡의 드롭 시각 − 7.5초"를 시작점으로 잡으면 컷과 맞습니다.

## B. 롱테이크 일상 브이로그 — 편집을 최소로, 관찰 자막만
```
input 폴더 영상으로 롱테이크 브이로그 릴스 만들어줘. 오늘 있었던 일: "[예: 강아지 목욕시키는데 도망다님]"
```
- 화면에 안 보이는 사정(누가 먼저 했는지 등)은 클로드가 **먼저 물어봅니다** — 추측으로 쓰면 이야기가 뒤집힙니다.
- 자막은 반말 일기체(`ㅋ`·`ㅠ` 포함)로 작게 들어갑니다.

## C. 인물 인서트 — 말하는 영상에 단어별 자막 + 모션그래픽
```
input 폴더 영상으로 인물 인서트 스타일 릴스 만들어줘. 핵심 키워드는 민트로 팝, 설명 구간엔 모션그래픽 넣어줘.
```
```
이 녹음에서 [상대방] 반응 부분을 증거로 끼워 넣어줘. 누가 말했는지는 목소리로 확인해줘.
```
- 말하는 순간 키워드가 민트로 튀고, 설명 구간은 배경이 흐려지며 카드 그래픽이 뜹니다.
- 제3자 목소리는 **발행 전에 본인 동의**를 받아주세요. 금액·실명은 자동으로 뺍니다.

## D. 화면 전용 설명편 — 얼굴 없이 화면 카드만
```
얼굴 없이 화면만으로 "[예: 초보가 헷갈리는 용어 5개]" 릴스 만들어줘. 데모 화면은 더미 데이터로 만들어서 찍어줘.
```
- 실제 내 계정·프로젝트 화면은 쓰지 않습니다(키·고객 정보가 찍힙니다).

## 이미 만든 릴스를 조금만 고칠 때
```
완성본에서 "[바꿀 문장]" 부분만 "[새 문장]"으로 바꿔줘. 나머지는 그대로 둬.
```
```
전체 속도만 1.2배로 올려줘. 다시 편집하지 말고.
```

# 7. 고치기 — 결과물을 보고 말하면 됩니다

## 자막
```
자막을 더 크게 해줘.
자막을 조금 더 위로 올려줘.
자막에서 "[단어]"만 노란색으로 강조해줘.
자막 강조색을 [#색상코드]로 바꿔줘.
자막을 화면 중앙으로 올려줘.
자막을 화면에 배치하는 스타일로 해줘 — 핵심 숫자는 크게. (키네틱)
자막이 한 번에 너무 많이 나와 — 더 짧게 끊어줘.
```

## 색·화면
```
색이 좀 바랜 것 같아. HDR 영상이면 톤매핑해서 다시 렌더해줘.
전체적으로 조금 더 밝게 해줘.
두 번째 컷에서 화면을 확대해줘.
세로로 잘릴 때 인물이 가운데 오게 해줘.
```

## 컷·길이
```
두 번째 컷이 너무 길어 — 짧게 줄여줘.
전체를 조금 더 빠르게 끊어줘.
전체 길이를 20초 안쪽으로 맞춰줘.
마지막에 여운이 없어 — 끝을 1초만 늘려줘.
```

## 화면 배치 바꾸기
```
내 얼굴은 아래쪽에 작게 깔고, 위는 자료로 채워줘.      (상하 분할)
이 부분은 자료를 화면 가득 보여줘.                      (자료 풀)
여기에 참고 화면을 작게 얹어줘. 배경은 흐리게.          (삽입)
이 문장은 글자만 크게 띄워줘.                           (타이포 단독)
같은 화면이 계속 나와 — 중간에 다른 배치로 바꿔줘.
```

## 자료 화면 (설명·사례형)
```
이 스크린샷을 아이폰 목업에 넣어서 화면에 띄워줘.
목업에서 [강조할 부분]을 빨간 원으로 표시해줘.
화살표로 [가리킬 곳]을 짚어줘.
```

## 타이틀·강조
```
인트로 타이틀 문구를 "[새 문구]"로 바꿔줘.
타이틀을 화면 위쪽으로 올려줘.
"[강조할 단어]" 부분에 강조 자막 한 컷 넣어줘.
브랜드 색 [#색상코드]을 타이틀과 강조 자막에 써줘.
```

## 나레이션
```
나레이션 톤이 좀 밋밋해 — 조금 더 밝게 다시 만들어줘.
[특정 문장]을 "[바꿀 문장]"으로 고쳐서 다시 만들어줘.
말이 너무 빨라 — 조금 천천히 해줘.
```

## 커버 (썸네일)
```
커버 2가지 스타일로 만들어서 보여줘.
커버는 투톤으로 — "[강조할 단어]"만 색 넣어줘.
커버를 감성적인 명조 스타일로 만들어줘.
커버를 박스 스타일로 바꿔줘.
커버 타이틀을 "[새 문구]"로 바꿔줘.
커버에 브랜드 색 [#색상코드] 써줘.
다른 프레임으로 커버 다시 뽑아줘 — 표정 좋은 걸로.
```

## 효과음 · 배경음
```
효과음 넣어줘.
효과음 후보 몇 개 들려줘 — 골라서 쓸게.   (215종 중 역할에 맞는 것)
마지막 강조 부분에만 효과음 하나 얹어줘.
효과음이 너무 커 — 작게 줄여줘.
자막을 검정 박스 스타일로 바꿔줘.
자막을 카라오케 스타일로 해줘.       (말하는 단어가 색으로 차오릅니다)
강조 단어에서 화면이 살짝 확대되게 해줘.   (펀치인 — 자동 동기화)
컷 전환에 글리치 효과 넣어줘.
배경음악 없이 나레이션만 남겨줘.
나레이션 나올 때만 배경음 작게 눌러줘.     (덕킹)
컷을 배경음 비트에 맞춰줘.
```

## 목소리가 어색할 때
```
나레이션 중에 다른 사람 목소리처럼 들리는 부분 찾아서 다시 만들어줘.
나레이션이 배경에 묻혀 — 먹히는 문장만 다시 뽑아줘.
문장 앞에 이상한 소리가 붙어 — 고쳐줘.
```
